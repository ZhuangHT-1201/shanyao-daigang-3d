# Contributing

This project is at a very early stage. Small, source-backed improvements are
especially valuable.

## Useful contributions

- Correct a road, building footprint, name, or location with a dated source.
- Add a licensed façade photograph or measured drawing.
- Improve a procedural material using a documented local reference.
- Report a reproducible rendering or interaction problem.
- Add local knowledge about shops, temples, salt production, or family houses.

## Source standards

Please provide:

- the source URL or archive reference;
- the image or map capture date, if known;
- WGS84 coordinates or a clearly marked map position;
- whether the information is measured, observed, or approximate.

Do not present an inferred façade, building height, or shop identity as a
surveyed fact.

## Pull requests

- Keep changes focused.
- Run `npm run build` before submitting.
- Explain which visual or data claim the change affects.
- Include a screenshot for visible interface or scene changes.

By contributing, you agree that your original code contributions are licensed
under the repository's MIT licence. Third-party data and media remain under
their respective licences.
